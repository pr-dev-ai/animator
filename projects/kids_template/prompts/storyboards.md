# Storyboard Prompts — kids_template

Placeholder prompts for the shots in `shotlist.csv`. Replace the bracketed text
with descriptions of your own song, characters, and title.

You do not have to edit this file by hand. The Storyboard tab in the web UI
generates a prompt for every shot from your lyrics and `styleguide.md`, then
overwrites this file (and writes a `storyboards.json` sidecar next to it).

## Style prefix (applied to every prompt)
```
cartoon, flat color, children's illustration, 2d, cute,
bright, bold outlines, simple shapes
```

## Negative prompt (applied to every prompt)
```
realistic, photo, dark, scary, complex background,
watermark, text, logo, adult
```
